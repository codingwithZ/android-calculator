# Android-calculator

This repository snippet is organized into three main parts for an Android calculator app:

- simple-calculator: Holds the core calculator logic and interface files including MainActivity.java.
- splash-screen: Covers the startup flow with SplashActivity.java and AndroidManifest.xml configuration so the loading screen launches first before opening the calculator screen.
- app logo: Covers custom logo creation in Figma along with importing and linking the exported ```app_logo.png``` asset and updating the mipmap launcher files.
